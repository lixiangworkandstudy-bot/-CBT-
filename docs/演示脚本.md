# 3分钟演示：慢慢星

## 开始前

- 启动服务，打开 `http://localhost:8787`。仅展示产品可用Windows启动；联动turtlesim时服务与适配器同在WSL运行。
- 使用成人扮演儿童做演示，明确不是儿童测试或真机录像。
- 仿真桥接器最长运行120秒，安排在演示联动前启动。网页URL中的session必须与适配器一致。

## 0:00–0:30：问题与边界

“这是慢慢星，一个基于CBT原则的游戏化陪伴原型，计划部署到大头机器狗。我们尝试让孩子能够用自主选择表达感受与需要，不要求口语回答、眼神接触或完成所有步骤。它需要熟悉的成人陪伴，不是诊断或治疗工具。”

展示首页与4个活动。选择“一起开始”，展示成人在场确认。

## 0:30–1:15：实际体验

心情气象站：选“多云·不确定” → “请大人陪我” → “我想试试”。

“没有正确的心情，也不会因为选了不舒服而扣分。我们先承认感受，再由孩子选择希望得到什么支持。”

如适配器已启动，展示turtlesim短暂原地旋转后停止，说明这只是同一条具身提示链路的二维仿真，并不代表机器狗已经执行。

## 1:15–1:50：CBT与沟通

回首页，选“勇气小桥”，展示同伴没有回应的情境：孩子可选择自己的感受；下一步提供“也许他没听见”等多个可能；最后选择“我可以一起玩吗”或“我需要帮助”。

“我们不纠正孩子的感受，也不替对方下结论，而是把可能的想法和可行的表达变成可选择的卡片。”

## 1:50–2:20：尊重退出

点“我想休息”，展示休息页；刷新页面仍保留休息状态。由成人确认后才能重新选择活动。说明动作租约会取消，软件停止不代替真机物理急停。

## 2:20–3:00：成果与下一步

展示共同回顾：仅保留选择、时间与活动，不是能力评分。展示导出和清除。最后打开海报，说明目前已经实现网页与真实turtlesim联动，SDK/设备授权/真机联调待现场确认。计划在主板运行服务和适配器，通过SSH转发给Windows浏览器访问。

## 附件说明

`demo.webm`/`demo.mp4` 是自动化浏览器实际操作录屏，时长较短，便于证明页面可用；本脚本用于人工讲解，不把自动化录屏描述为3分钟带旁白视频。需要有讲解的视频时，可按脚本自行屏录并配音。环境证明PNG是基于原始检查JSON的汇总可视化，不是假装成原始终端截图。
