# 慢慢星 · 绘本IP与视觉规范

参考与素材来源：用户提供的上一级 images 文件夹。原图保留不修改；网页使用本地处理后的 WebP，素材权利归原权利人，不包含在代码MIT授权中。

## IP定位

慢慢是金黄双辫、鼠尾草绿上衣、胸前小芽口袋的绘本伙伴，双手捧星星是主形象。人物IP与VBOT机器狗的硬件载体是两个不同层面：页面由慢慢陪伴引导，真机仍按既有机器人计划接入。

| 场景 | 用户素材 | 页面用途 |
| --- | --- | --- |
| 首页 / 海报 | 双手捧星星 | 主视觉、品牌识别 |
| 心情气象站 | 认真倾听 | 活动引导 |
| 情绪卡片 | 情绪识别表情组 | 自主选择的辅助图示，不用来推断儿童情绪 |
| 云朵充电站 | 呼吸放松 | 自愿呼吸练习 |
| 轮流小星球 / 完成页 | 欢迎沟通 | 轮流与结束反馈 |
| 休息页 | 表达需要 | 休息卡，明确可停止 |

## 色调与纹理

主视觉钴蓝 #2858A9，暖纸底色 #F7F2E5，星星黄 #FFE5A0，文字暖棕 #4D433C，鼠尾草绿用于辅助卡片。钴蓝集中在首页故事画面，活动页以低对比纸张底为主，文字和操作保持清晰。

蓝色蜡笔纹理由用户原图空白背景区域提取，暖米纸张以低幅度静态颗粒生成。保留笔触、不添加闪烁或持续粒子动画；减少动态仍默认开启。大图使用透明背景WebP，保持金黄头发、绿色衣服和原始蜡笔肌理。

## 素材与复现

app/web/assets 为已优化素材，运行产品不依赖图像处理库。重新处理素材可运行 scripts/prepare_visual_assets.py，需要 Pillow 与 NumPy。原始图片不打入代码包，降低体积；处理结果随项目分发。海报源和截图已同步本视觉版本。
